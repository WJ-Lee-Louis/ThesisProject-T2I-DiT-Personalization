# 정성 비교용 최대 향상·하락 사례

각 실험 조건 이미지를 동일한 `record_id + seed`의 baseline과 pairing했다. DPG는 dependency-aware `dpg_with_dependency`, IP-Sim은 `ip_similarity`의 차이(`실험 조건 - baseline`)다.

경로는 이 문서가 있는 실험 폴더를 기준으로 하며, 각 행의 자료 링크는 `비교 이미지/mask/crop · baseline 이미지/mask/crop · reference 이미지/mask/crop` 순서다. DPG 사례의 mask와 crop도 같은 이미지에 대한 IP-Sim pipeline 산출물이다.

DPG는 이산 점수이므로 최대 향상 동률이 존재한다. Top-5 경계에서 동률이면 표준 조건 순서(SSG, target, source, ST-matched, ST-all), record ID, seed 순으로 5개를 선택했다. `경계 동률 수`를 함께 표시해 임의의 유일 순위로 오해하지 않게 했다.
