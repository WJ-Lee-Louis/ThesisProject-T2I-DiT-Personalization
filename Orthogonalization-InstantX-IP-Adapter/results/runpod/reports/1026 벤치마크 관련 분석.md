# Projection·SSG 실험 결과의 최종 해석

작성일: 2026-10-26 (한국시간)

이 문서는 대화에서 합의한 결과 해석과 그 근거를 정리한다. 표 이미지 생성·수정 이력은 포함하지 않는다.

## 1. 분석 전제

- Baseline은 **InstantX-IP-Adapter, IP scale 0.7**이다. scale은 사용자 확인 사항이다.
- Ours는 semantic projection과 single-stream gate(SSG)를 함께 적용한 방법이다.
- Ours scale sensitivity 범위는 0.6, 0.7, 0.8, 0.9, 1.0이다.
- CLIP-I·DINO-I는 이미지 충실도, CLIP-T는 텍스트 정합성 평가 지표로 해석한다. 모두 높을수록 좋다.
- 집계는 기존 평가의 **subject macro average**를 따른다. DreamBench는 조건당 750장, DreamBench++는 조건당 1,350장이다.
- Baseline과 Ours scale 0.7은 기존 스크린샷 전사값(소수점 네 자리)이다. 그 외 로컬 실험은 평가 JSON을 사용했다.
- 아래의 작은 차이는 통계적 유의성을 의미하지 않는다. 반복 seed 실험이나 유의성 검정은 수행하지 않았다.

## 2. 전체 성능과 scale에 따른 trade-off

scale을 높이면 두 벤치마크에서 CLIP-I·DINO-I가 일관되게 상승하고 CLIP-T는 하락한다. 따라서 하나의 지표만으로 모든 목적에 공통된 최적 scale을 정할 수는 없다.

|---|---|---:|---:|---:|
| DreamBench | Baseline (scale 0.7) | 0.8319 | 0.2939 | 0.6900 |
| DreamBench | Ours (scale 0.6) | 0.7870 | 0.3165 | 0.6324 |
| DreamBench | Ours (scale 0.7) | 0.8022 | 0.3123 | 0.6548 |
| DreamBench | Ours (scale 0.8) | 0.8144 | 0.3078 | 0.6726 |

| DreamBench++ | Ours (scale 0.6) | 0.7945 | 0.3331 | 0.5869 |

### 2.1 인접 scale 사이의 변화율

각 수치는 직전 scale 대비 상대 변화율이다. 서로 범위가 다른 지표의 절대 증감폭을 그대로 비교하지 않기 위한 보조 분석이며, 변화율 자체가 지표 간 중요도를 결정하지는 않는다.

| 벤치마크 | scale 변화 | Δ CLIP-I | Δ CLIP-T | Δ DINO-I |
|---|---|---:|---:|---:|
| DreamBench | 0.6 → 0.7 | +1.94% | -1.33% | +3.55% |
| DreamBench | 0.7 → 0.8 | +1.51% | -1.45% | +2.71% |
| DreamBench | 0.8 → 0.9 | +1.34% | -1.32% | +2.21% |
| DreamBench | 0.9 → 1.0 | +1.23% | -1.52% | +2.05% |
| DreamBench++ | 0.6 → 0.7 | +2.14% | -1.53% | +4.86% |
| DreamBench++ | 0.7 → 0.8 | +1.95% | -2.20% | +4.21% |
| DreamBench++ | 0.8 → 0.9 | +1.65% | -2.63% | +3.49% |
| DreamBench++ | 0.9 → 1.0 | +1.40% | -2.40% | +2.52% |

이미지 지표의 추가 개선폭은 scale이 높아질수록 줄어든다. 반면 텍스트 손실은 그에 비례해 줄지 않는다. 특히 DreamBench++의 0.8 → 0.9에서는 직전 구간보다 이미지 개선폭이 줄고 텍스트 손실이 커진다. DreamBench에서는 0.8 → 0.9의 텍스트 손실이 직전 구간보다 작으므로, 두 벤치마크 모두에서 명확한 단일 꺾임이 존재한다고 단정할 수는 없다.

## 3. scale 0.8·0.9·1.0의 역할

| scale | 해석 | 적합한 목적 |
|---|---|---|
| 0.8 | 이미지와 텍스트를 동등하게 고려한 균형 중심 설정 | 두 평가 축 사이의 균형 |
| 0.9 | 이미지 충실도를 더 확보하면서 텍스트 개선을 유지하는 설정 | 일정한 이미지 손실을 허용하는 보존 중심 절충 |
| 1.0 | baseline 수준의 이미지 충실도 회복을 가장 우선하는 설정 | 이미지 지표 손실을 거의 허용하지 않는 비교 |

**대화의 최종 판단:** 0.8–0.9는 유용한 절충 구간이다. 이미지 지표를 더 보수적으로 보존하려는 목적에서는 0.8보다 0.9를 선호할 수 있다. 다만 이미지 보존을 최우선으로 하면 현재 수치에서는 1.0이 더 부합한다.

### 3.1 baseline 대비 상대 변화율

| 벤치마크 | Ours scale | Δ CLIP-I | Δ CLIP-T | Δ DINO-I |
|---|---:|---:|---:|---:|
| DreamBench | 0.8 | -2.11% | +4.72% | -2.53% |
| DreamBench | 0.9 | -0.80% | +3.34% | -0.37% |
| DreamBench | 1.0 | +0.41% | +1.77% | +1.67% |
| DreamBench++ | 0.8 | -3.06% | +7.14% | -5.96% |
| DreamBench++ | 0.9 | -1.46% | +4.33% | -2.68% |
| DreamBench++ | 1.0 | -0.08% | +1.83% | -0.23% |

DreamBench의 scale 0.9는 이미지 지표 손실이 모두 1% 미만이다. DreamBench++에서는 CLIP-I가 약 1.46%, DINO-I가 약 2.68% 낮으므로, 이 손실을 허용하고 CLIP-T 약 4.33% 개선을 얻는 선택이다.

scale 1.0에서는 DreamBench의 세 지표가 모두 baseline을 상회한다. DreamBench++에서는 이미지 지표가 baseline에 매우 근접하면서 CLIP-T가 약 1.83% 높다.

### 3.2 정규화된 이상점 거리 분석

각 벤치마크에서 scale 0.6–1.0의 관측 최솟값·최댓값으로 지표별 min–max 정규화를 적용한다.

`normalized(metric) = (metric − observed_min) / (observed_max − observed_min)`

텍스트 축을 정규화 CLIP-T, 이미지 축을 아래 세 방식 중 하나로 두고 이상점 (1, 1)까지의 유클리드 거리를 계산한다.

- 정규화 CLIP-I와 정규화 DINO-I의 평균
- 정규화 CLIP-I 단독
- 정규화 DINO-I 단독

`distance = sqrt((1 − image_axis)^2 + (1 − text_axis)^2)`

| 벤치마크 | scale | 이미지 평균 거리 ↓ | CLIP-I 단독 거리 ↓ | DINO-I 단독 거리 ↓ |
|---|---:|---:|---:|---:|
| DreamBench | 0.6 | 1.0000 | 1.0000 | 1.0000 |
| DreamBench | 0.7 | 0.7220 | 0.7265 | 0.7175 |
| DreamBench | 0.8 | 0.6583 | 0.6632 | 0.6534 |
| DreamBench | 0.9 | 0.7639 | 0.7646 | 0.7631 |
| DreamBench | 1.0 | 1.0000 | 1.0000 | 1.0000 |
| DreamBench++ | 0.6 | 1.0000 | 1.0000 | 1.0000 |
| DreamBench++ | 0.7 | 0.7243 | 0.7305 | 0.7181 |
| DreamBench++ | 0.8 | 0.6105 | 0.6169 | 0.6041 |
| DreamBench++ | 0.9 | 0.7591 | 0.7621 | 0.7563 |
| DreamBench++ | 1.0 | 1.0000 | 1.0000 | 1.0000 |

세 방식 모두 두 벤치마크에서 scale 0.8을 선택한다. 따라서 이 결과는 이미지 지표를 평균했기 때문에 발생한 것은 아니다. 다만 **관측 범위에 따른 정규화와 이미지·텍스트의 동일 가중치**를 전제로 한 보조적 선택 기준이다. 이미지 보존을 더 중요하게 보는 scale 0.9 선호와 모순되지 않는다.

## 4. Scaling으로 이미지 충실도를 맞추는 비교의 타당성

Ours scale 0.7의 CLIP-T 개선과 이미지 지표 저하만 제시하면, 텍스트 개선이 이미지 충실도를 희생한 결과라는 해석이 남는다. 따라서 scale을 높여 **baseline 수준의 이미지 충실도를 회복하면서도 텍스트 개선이 유지되는지** 확인하는 것은 타당한 비교다.

현재 결과는 다음 주장을 뒷받침한다.

> Ours는 IP scale 조정을 통해 이미지 충실도를 baseline에 근접하게 회복하면서 더 높은 텍스트 정합성을 유지한다.

단, 이는 baseline scale 0.7과 Ours의 조정된 scale을 비교하는 **운용 설정 비교**다. 동일 scale 0.7 ablation은 구성요소 효과를 보여주고, scaling 결과는 활용 가능한 성능 절충점을 보여주므로 서로 다른 역할로 제시한다.

method 자체가 더 좋은 trade-off를 제공한다는 주장을 강화하려면 baseline도 scale sweep하여 두 방법의 이미지–텍스트 성능 곡선을 비교해야 한다. baseline의 scale을 낮추는 것만으로 유사한 결과를 얻을 수 있는지 확인하는 절차가 필요하다.

## 5. Projection·SSG ablation 해석

아래는 모두 scale 0.7이다. Proj.는 projection만 적용, SSG는 gate만 적용, Ours는 두 방법을 결합한 경우다.

| 벤치마크 | 방법 | CLIP-I ↑ | CLIP-T ↑ | DINO-I ↑ |
|---|---|---:|---:|---:|
| DreamBench | Baseline | 0.8319 | 0.2939 | 0.6900 |
| DreamBench | + Proj. | 0.8244 | 0.3017 | 0.6806 |
| DreamBench | + SSG | 0.8069 | 0.3090 | 0.6616 |
| DreamBench | Ours | 0.8022 | 0.3123 | 0.6548 |
| DreamBench++ | Baseline | 0.8534 | 0.2994 | 0.6820 |
| DreamBench++ | + Proj. | 0.8414 | 0.3087 | 0.6618 |
| DreamBench++ | + SSG | 0.8206 | 0.3220 | 0.6335 |
| DreamBench++ | Ours | 0.8115 | 0.3280 | 0.6154 |

두 벤치마크의 전체 집계에서 다음 경향이 공통적으로 관찰된다.

- Projection 단독은 SSG 단독보다 이미지 지표가 높다.
- SSG 단독은 projection 단독보다 CLIP-T가 높다.
- 결합한 Ours는 CLIP-T가 가장 높지만 이미지 지표는 가장 낮다.

따라서 어느 한 구성요소가 모든 지표의 개선을 압도적으로 이끈다고 보기 어렵다. 두 요소가 서로 다른 절충을 제공하고, 결합 시 텍스트 정합성이 추가로 개선된다고 해석할 수 있다. 전 지표 개선이나 통계적 상승효과가 입증됐다는 주장은 피한다. **최종 선택 scale에서의 ablation은 후속 검증 과제**다.

## 6. FreeCus 대비 해석

제공된 DreamBench 비교 이미지의 FreeCus 값은 CLIP-I 0.8058, CLIP-T 0.3004, DINO-I 0.6708이다.

| Ours scale | FreeCus 대비 Δ CLIP-I | Δ CLIP-T | Δ DINO-I |
|---|---:|---:|---:|
| 0.8 | +0.0086 | +0.0074 | +0.0018 |
| 0.9 | +0.0194 | +0.0033 | +0.0166 |

두 scale 모두 FreeCus의 제공 수치를 세 지표에서 상회한다. 0.8은 텍스트 정합성에서, 0.9는 이미지 충실도에서 상대적으로 더 큰 이점을 보인다.

단, FreeCus 값은 제공 이미지에서 가져왔다. 직접적인 비교 우위를 주장하려면 동일한 평가 프로토콜·reference 선택·집계 방식인지 확인해야 한다. DreamBench++의 FreeCus 결과는 본 분석에 없다. FreeCus를 핵심 비교군으로 선정하는 근거는 성능뿐 아니라 문제 설정과 방법론의 유사성도 포함해야 한다.

## 7. Projection 전후 norm 해석

현재 실험은 `restore_visual_norm=True`다. Projection으로 성분을 제거한 후 남은 벡터를 rescale하여 원래 pooled embedding의 L2 norm으로 복원한다.

`e_out = ((e − P e) / ||e − P e||₂) × ||e||₂`

즉, 일반적인 비퇴화 사례에서는 **방향은 바뀌고 크기는 복원된다**. 기존 norm 분석에서 퇴화 사례가 발생했다는 보고는 없지만, 수식은 남은 벡터의 norm이 0이 아닌 경우를 전제로 한다.

Ours scale 0.8의 전체 2,100건에서 복원 전 감소율 `100 × (1 − adjusted_unit_norm)`을 subject macro 평균으로 집계한 결과는 다음과 같다.

| 벤치마크 | Class | 복원 전 pooled embedding norm 감소율 |
|---|---|---:|
| DreamBench | overall | 0.4188% |
| DreamBench | animal | 0.4537% |
| DreamBench | object | 0.4039% |
| DreamBench++ | overall | 0.7083% |
| DreamBench++ | animal | 0.5628% |
| DreamBench++ | human | 0.8095% |
| DreamBench++ | object | 0.6303% |
| DreamBench++ | style | 1.1879% |

복원 후 감소율은 두 벤치마크 모두 사실상 0%이며, 개별 사례의 최대 절대 오차도 약 0.000016% 이하이다. 이는 **BF16 변환과 image projector 통과 전 pooled embedding**의 기록이다.

실제 흐름은 다음과 같다.

`pooled embedding → semantic projection → norm 복원 → image projector → IP K/V → attention → scale × IP residual`

이후에는 벡터 방향 변화가 image projector와 attention을 통해 residual norm에 영향을 줄 수 있다. 따라서 pooled embedding norm 감소율을 DiT에 주입되는 IP residual 감소율로 해석할 수 없고, residual이 반드시 감소한다고도 할 수 없다. **기존 결과에는 실제 block별·timestep별 IP residual norm이 저장되어 있지 않다.**

이를 검증하려면 동일한 hidden state·query·scale·SSG 조건에서 projection ON/OFF의 residual을 함께 계산하고, 이미지 token 기준 block별·timestep별 norm 비율을 기록해야 한다. 독립 생성 결과만 비교하면 생성 경로 변화까지 섞이므로 projection 자체의 효과와 구분해야 한다.

## 8. 최종적으로 제시할 수 있는 주장과 후속 검증

### 현재 결과로 지지되는 해석

1. Ours는 scale을 통해 이미지 충실도와 텍스트 정합성의 균형을 조정할 수 있다.
2. 이미지·텍스트 동등 가중치의 정규화 거리 기준에서는 scale 0.8이 가장 균형적이다.
3. 이미지 지표 보존을 더 중시하면 scale 0.9가 합리적인 절충이며, baseline 수준 회복을 최우선으로 하면 1.0이 적합하다.
4. DreamBench의 scale 1.0은 baseline scale 0.7보다 세 지표가 모두 높다. DreamBench++는 이미지 지표가 거의 같고 CLIP-T가 높다.
5. Scale 0.7 ablation에서 projection과 SSG의 결합은 CLIP-T를 추가로 높이지만 이미지 지표 손실도 동반한다.
6. DreamBench에서 Ours scale 0.8·0.9는 FreeCus의 제공 수치를 세 지표 모두 상회한다.
7. Semantic projection 후 pooled embedding의 norm은 rescale로 복원된다. 실제 DiT IP residual norm 변화는 별도 계측이 필요하다.

### 후속 검증 과제

- Baseline scale sweep을 통한 두 방법의 trade-off 곡선 비교.
- 최종 선택 scale에서의 projection·SSG ablation.
- 반복 seed 및 적절한 통계 분석을 통한 차이의 안정성 확인.
- FreeCus와의 평가 조건 일치 여부 확인.
- 동일 query 조건에서 projection ON/OFF의 실제 IP residual norm 계측.
